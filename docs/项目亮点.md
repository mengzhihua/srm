# SRM 亮点

SRM 把采购从申请做到收货和发票匹配，并和仓储、ERP 演示系统连上。

1. **主链路是一条，不是散落的单据。** 采购申请、询价、采购订单、供应商确认、发货通知、收货、考核、三单匹配，按这个顺序往下走。
2. **发货通知会变成仓储入库单。** 收货数量从仓储回传后，本系统生成收货单，并模拟 ERP 收货过账。
3. **控制塔能推动采购，但越不过本系统的单据。** 采购建议生成申请，提交和审批走申请号，催单走采购订单号。重复指令按幂等键返回第一次的结果。
4. **没有开放密钥时仍能用业务账号办事。** 控制塔登录后创建申请、提交、审批和更新采购订单，不要求每个环境先发 API Key。
5. **供应商不只是主数据。** 快照里带供应商状态，考核结果可以随收货协同推进。
